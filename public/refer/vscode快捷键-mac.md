重点
	删除当前行
		⇧ + ⌘ + K
	文件内检索
		command + f
		下一个
			command + G
		上一个
			shift + command + G
	格式化代码
		⇧ + ⌥ + F
	关闭文件
		⌘ + W
	上下移动当前行
		⌥ + ↓ / ⌥ + ↑
	向下/向上复制当前行
		⇧ + ⌥ + ↓ / ⇧ + ⌥ + ↑
	在当前行下方/上方插入新行
		⌘ + Enter / ⇧ + ⌘ + Enter
	新建文件
		⌘ + N
	快速打开文件
		⌘ + P
	显示搜索
		⇧ + ⌘ + F
	跳转到文件开头/结尾
		⌘ + ↑ / ⌘ + ↓
	剪切行（无选择内容时）
		⌘ + X
	复制行（无选择内容时）
		⌘ + C
	缩进/减少缩进
		⌘ + ] / ⌘ + [
	跳转到行首/行尾
		command + ⬅️
		command + ➡️
	打开命令面板
		⇧ + ⌘ + P
	上下滚动当前行
		⌃ + PgUp / ⌃ + PgDn
	折叠/展开区域
		⌥⌘[ / ⌥⌘] 
	折叠/展开所有子区域
		⌘K ⌘[ / ⌘K ⌘] 
	折叠/展开所有区域
		⌘K ⌘0 / ⌘K ⌘J
	切换行注释
		⌘ + /
	切换块注释
		⇧ + ⌥ + A
