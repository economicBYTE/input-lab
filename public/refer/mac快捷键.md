常用快捷键一
	创建一个访达窗口
		Command-N：打开一个新的“访达”窗口。
	关闭访达窗口
		command + w
	打开启动台
		ctrl + f4
			访问程序列表
	切换桌面级窗口
		ctrl + f3
	最小化窗口
		Command-M：将最前方窗口最小化至程序坞。
		Option-Command-M：最小化最前方 App 的所有窗口。
	聚焦搜索
		显示/隐藏聚焦搜索栏
			Command-空格键：显示或隐藏“聚焦”搜索栏。
			Command–Option–空格键：从“访达”窗口启动“聚焦”搜索。
	新建与关闭
		新建标签页
			Command-T：打开新标签页。
		关闭窗口
			Command-W：关闭最前方窗口。
			Option-Command-W：关闭 App 的所有窗口。
	全屏使用 App
		Control-Command-F：以全屏模式使用 App（需支持）。
	切换应用程序
		command + tab
	显示或隐藏程序坞。
		Option-Command-D
	访问指定路径文件夹
		Shift-Command-G：打开“前往文件夹”窗口。
	关闭应用程序
		command + q
	创建文件夹
		shift + command + n

	窗口与 App 切换
		切换到最近使用的 App
			Command-Tab：切换到下一个最近使用的 App。
		全屏使用 App
			Control-Command-F：以全屏模式使用 App（需支持）。

		查找文稿中的项目或打开“查找”窗口。
			Command-F：
		查找下一处匹配项。
			Command-G：
		查找上一处匹配项。
			Shift-Command-G：
	导航文件夹
		前往上一个文件夹。
			Command-左中括号 ([)：
		前往下一个文件夹。
			Command-右中括号 (])：
		打开包含当前文件夹的文件夹。
			Command-上箭头：
		在新窗口中打开包含当前文件夹的文件夹。
			Command-Control-上箭头：
		打开所选项目。

		使用“快速查看”预览所选文件。

	文件检索（访达）
		command + f
	切换当前 App 的窗口 
		Command-重音符 (`)：切换当前 App 的各个窗口。
		仅在窗口未最大化时生效
	文件操作
		在当前目录下制作文件替身
			Control-Command-A：为所选项目制作替身。
		复制所选文件。
			Command-D：
		复制文件并拖拽移动到指定目录
			Option-Command-拖移：为拖移的项目制作替身。
		将文件复制到剪切板中
			command + c
		移动剪切板中的文件
			Option-Command-V：将剪贴板中的文件从原始位置移动到当前位置。
		创建文件夹
			shift + command + n
		将所选项目移到废纸篓。
