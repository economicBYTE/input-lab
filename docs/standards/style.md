# TypePractice 样式风格规范

> 版本: 1.0 | 日期: 2026-03-19

## 1. 设计风格

**现代极简 + 扁平化**，参照 MonkeyType 的专注练习体验。

- 干净留白，信息层次清晰
- 扁平化图标与按钮，无多余装饰
- 功能优先，视觉轻量

## 2. 色彩体系

### 2.1 基础色

| 用途 | 色值 | 说明 |
|------|------|------|
| 主色 | `#1890ff` | Ant Design 蓝，用于高亮、链接、主按钮 |
| 成功 | `#52c41a` | 正确反馈 |
| 错误 | `#ff4d4f` | 错误字符、警告 |
| 警告 | `#faad14` | 提示信息 |

### 2.2 中性色

| 用途 | 色值 | 说明 |
|------|------|------|
| 标题文字 | `#333333` | 主要标题、统计数值 |
| 正文文字 | `#666666` | 正文内容 |
| 辅助文字 | `#999999` | 标签、提示、已完成字符 |
| 占位符 | `#bbbbbb` | 特殊字符符号（空格·换行·Tab） |
| 分割线 | `#f0f0f0` | 边框、分隔 |
| 背景色 | `#f5f5f5` | 页面背景 |
| 卡片背景 | `#ffffff` | 卡片、面板 |

### 2.3 练习专用色

| 状态 | 背景 | 边框/文字 |
|------|------|-----------|
| 当前字符 | `#e6f7ff` | 底边 `#1890ff` |
| 错误字符 | `#fff2f0` | 底边 + 文字 `#ff4d4f` |
| 已完成字符 | 无 | 文字 `#999999` |

## 3. 字体

### 3.1 系统字体栈

```css
/* 界面文字 */
font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, 'Helvetica Neue', Arial, sans-serif;

/* 代码/练习区 */
font-family: 'Monaco', 'Menlo', 'Ubuntu Mono', monospace;
```

### 3.2 字号规范

| 层级 | 字号 | 用途 |
|------|------|------|
| 标题 H2 | `24px` | 页面主标题（如"练习完成"） |
| 标题 H3 | `20px` | 区域标题（如"选择文档开始练习"） |
| 统计数值 | `24px` / `font-weight: 600` | KPM、错误率等数值 |
| 练习字符 | `24px` | 字符显示区 |
| 正文 | `14px` | 默认正文 |
| 辅助标签 | `12px` | 统计标签、字符数提示 |

### 3.3 行高

| 场景 | 行高 |
|------|------|
| 练习字符区 | `1.8` |
| 正文 | `1.5` |

## 4. 间距

基于 **8px 网格系统**，所有间距为 8 的倍数。

| 级别 | 值 | 用途 |
|------|------|------|
| xs | `4px` | 标签与数值间距 |
| sm | `8px` | 紧凑元素间距 |
| md | `16px` | 卡片内边距、列表间距 |
| lg | `24px` | 页面边距、区块间距 |
| xl | `32px` | 练习区内边距、大区块间距 |
| xxl | `48px` | 统计面板间距、结果页区块间距 |

## 5. 布局

### 5.1 页面容器

```
最大宽度: 1200px
水平居中: margin: 0 auto
内边距: 24px
最小高度: 100vh
```

### 5.2 栅格

文档列表使用 Ant Design 响应式栅格：

| 断点 | 列数 |
|------|------|
| xs（<576px） | 1 列 |
| sm（≥576px） | 2 列 |
| md（≥768px） | 2 列 |
| lg（≥992px） | 3 列 |
| xl（≥1200px） | 3 列 |

栅格间距: `16px`

### 5.3 练习页布局

```
flex 纵向居中
字符显示区最大宽度: 900px, 宽度: 100%
统计面板: flex 横向排列, gap: 48px
```

## 6. 圆角与阴影

### 6.1 圆角

| 元素 | 圆角 |
|------|------|
| 卡片/面板 | `8px` |
| 按钮 | Ant Design 默认（`6px`） |
| 标签 Tag | Ant Design 默认（`4px`） |

### 6.2 阴影

| 场景 | 阴影 |
|------|------|
| 默认卡片 | `0 2px 8px rgba(0, 0, 0, 0.06)` |
| 悬停卡片 | `0 4px 12px rgba(0, 0, 0, 0.1)` |

## 7. 交互与动效

| 交互 | 效果 | 时长 |
|------|------|------|
| 卡片悬停 | `translateY(-4px)` + 阴影增强 | `0.2s` |
| 字符状态切换 | `all` 过渡 | `0.1s` |
| 错误字符 | `scale(1.2)` 放大 | 即时 |

## 8. 组件规范

### 8.1 卡片 Card

- 背景白色，圆角 `8px`
- 悬停时上浮 + 阴影增强
- 高度自适应内容

### 8.2 统计面板

- 白色背景，水平排列
- 标签在上（12px 灰色），数值在下（24px 粗体）
- 各项间距 `48px`

### 8.3 按钮

- 主操作：`type="primary"`，`size="large"`
- 次操作：默认样式，`size="large"`
- 按钮组间距：Ant Design Space `size="large"`

### 8.4 标签 Tag

- 错误字符展示：`color="error"`
- 字号 `16px`，内边距 `4px 12px`

## 9. 特殊字符显示

练习区对不可见字符使用符号替代：

| 字符 | 显示符号 | 颜色 |
|------|----------|------|
| 换行 `\n` | `↵` + 换行 | `#bbbbbb`（当前态 `#1890ff`，错误态 `#ff4d4f`） |
| Tab `\t` | `→` | 同上 |
| 空格 ` ` | `·` | 同上 |
