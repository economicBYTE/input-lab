# US-2.3.1 完成统计

> 优先级: P0 | 关联功能: F007

## 用户故事

**作为**一名开发者，
**我想要**在完成一篇文档练习后看到详细统计，
**以便**了解本次练习效果和需要加强的字符。

## 验收标准

- [ ] 输入最后一个字符后显示完成界面
- [ ] 显示总练习时长
- [ ] 显示平均 KPM
- [ ] 显示错误率
- [ ] 显示错误字符列表（去重）
- [ ] 练习记录保存到 IndexedDB

## 统计数据

| 数据项 | 说明 |
|--------|------|
| 总时长 | 从第一次击键到最后一次击键 |
| KPM | 总字符数 / 总时长（分钟） |
| 错误率 | 错误次数 / 总击键次数 |
| 错误字符 | 所有输错的目标字符（去重列表） |

## 界面要素

- 完成提示
- 统计数据卡片
- 错误字符展示
- 再练一次按钮
- 返回列表按钮
