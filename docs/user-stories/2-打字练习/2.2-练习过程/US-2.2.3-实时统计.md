# US-2.2.3 实时统计

> 优先级: P0 | 关联功能: F005, F006

## 用户故事

**作为**一名开发者，
**我想要**在练习过程中实时看到打字速度和错误率，
**以便**了解当前练习状态。

## 验收标准

- [ ] 实时显示 KPM（击键/分钟）
- [ ] 实时显示错误率（错误次数/总输入次数）
- [ ] 数据每次击键后更新
- [ ] 统计面板不干扰练习区域

## 计算公式

```
KPM = (已输入字符数 / 已用时间分钟数)
错误率 = (错误次数 / 总击键次数) × 100%
```

## 界面要素

- KPM 数值显示
- 错误率百分比显示
- 统计面板（固定位置）

## 扩展（P1）

- 支持 WPM 显示（5字符 = 1单词）
