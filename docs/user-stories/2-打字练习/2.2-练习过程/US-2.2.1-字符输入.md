# US-2.2.1 字符输入

> 优先级: P0 | 关联功能: F003

## 用户故事

**作为**一名开发者，
**我想要**逐字符对照输入练习内容，
**以便**通过打字练习强化技术命令的记忆。

## 验收标准

- [ ] 显示完整的文档内容
- [ ] 当前待输入字符高亮显示
- [ ] 已正确输入的字符有区分样式
- [ ] 键盘输入字符与目标字符对比
- [ ] 正确输入后自动前进到下一字符
- [ ] 支持多行内容，换行符作为可输入字符
- [ ] 输入响应延迟 < 50ms

## 界面要素

- 文档内容展示区
- 当前字符高亮指示
- 已输入内容区分样式
- 光标位置指示

## 交互细节

- 当前字符：高亮背景 + 下划线
- 已输入正确：普通样式或淡化
- 未输入：普通样式
- 支持 Tab、空格、换行等特殊字符
