# US-2.2.2 错误处理

> 优先级: P0 | 关联功能: F004

## 用户故事

**作为**一名开发者，
**我想要**在输入错误时得到明确反馈并强制重输，
**以便**加深对正确字符的记忆。

## 验收标准

- [ ] 输入错误字符时，当前字符标红
- [ ] 错误字符放大显示，强调错误
- [ ] 错误时阻止前进，必须输入正确字符
- [ ] 输入正确后恢复正常样式并前进
- [ ] 记录错误次数和错误字符

## 界面要素

- 错误状态样式（红色 + 放大）
- 错误提示动画（可选：抖动效果）

## 交互细节

- 错误时：字符红色 + 1.2倍放大
- 不播放错误音效（避免打扰）
- 错误计数累加，用于统计
