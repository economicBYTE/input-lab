# US-2.1.2 智能推荐

> 优先级: P1 | 关联功能: F013

## 用户故事

**作为**一名开发者，
**我想要**系统根据我的练习情况推荐文档，
**以便**优先练习易错和重点内容。

## 验收标准

- [ ] 首页显示推荐练习区域
- [ ] 优先推荐重点标记的文档
- [ ] 优先推荐历史错误率高的文档
- [ ] 推荐列表最多显示 5 篇

## 推荐算法

优先级排序：
1. 重点标记 + 高错误率
2. 重点标记
3. 高错误率
4. 最近未练习

## 界面要素

- 推荐练习卡片区域
- 推荐原因标签（重点/易错）

## 依赖

- US-1.4.1 标记重点
- US-3.1.1 历史记录列表
