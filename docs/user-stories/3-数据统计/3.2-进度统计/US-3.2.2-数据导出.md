# US-3.2.2 数据导出

> 优先级: P2 | 关联功能: F021

## 用户故事

**作为**一名开发者，
**我想要**导出我的练习数据，
**以便**备份或在其他设备使用。

## 验收标准

- [ ] 设置页面提供数据导出功能
- [ ] 导出格式为 JSON
- [ ] 包含所有文档和练习记录
- [ ] 下载文件命名包含导出时间

## 界面要素

- 导出按钮
- 导出进度提示
- 下载确认

## 导出格式

```json
{
  "exportTime": "2026-01-28T10:00:00Z",
  "documents": [...],
  "practiceRecords": [...]
}
```
