# US-1.2.1 新增文档

> 优先级: P0 | 关联功能: F002

## 用户故事

**作为**一名开发者，
**我想要**新增自定义的练习文档，
**以便**练习我需要记忆的技术命令或代码片段。

## 验收标准

- [ ] 点击新增按钮打开文档表单
- [ ] 必填：文档标题
- [ ] 必填：文档内容（仅支持英文字符）
- [ ] 选填：文档简介
- [ ] 保存后文档出现在列表中
- [ ] 保存后数据持久化到 IndexedDB

## 界面要素

- 新增按钮
- 文档表单（标题、内容、简介）
- 保存/取消按钮

## 校验规则

- 标题不能为空
- 内容不能为空
- 内容仅支持英文字符（字母、数字、符号、空格、换行）
