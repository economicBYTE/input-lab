mac chrome浏览器快捷键
	标签页快捷键
		打开新的标签页：⌘ + t
		跳转到下一个标签页：⌘ + Option + 向右键
		跳转到上一个标签页：⌘ + Option + 向左键
		重新打开先前关闭的标签页：⌘ + Shift + t
		跳转到特定标签页：⌘ + 1 到 ⌘ + 8
		跳转到最后一个标签页：⌘ + 9
		关闭当前标签页：⌘ + w
	窗口快捷键
		打开新窗口：⌘ + n
		最小化窗口：⌘ + m
		在无痕模式下打开新窗口：⌘ + Shift + n
		隐藏 Google Chrome：⌘ + h
		退出 Google Chrome：⌘ + q
		关闭当前窗口：shift + ⌘ + w
	功能快捷键
		显示或隐藏书签栏：⌘ + Shift + b
		打开“设置”：⌘ + ,
		打开“下载内容”：⌘ + Shift + j
		查找网页内容：⌘ + f
		打开开发者工具：⌘ + Option + i / fn  + f12
		打开“历史记录”：⌘ + y
		开启拆分视图：⌘ + Option + n
			一个网页中可以展示多个网址内容
	地址栏快捷键
		跳转到地址栏：⌘ + l
		跳转到地址栏（光标移动）：Ctrl + F5
		为网站添加 www 和 .com：Ctrl + Return
	网页快捷键
		打开打印选项：⌘ + p
		保存网页：⌘ + s
		放大网页：⌘ + +
		缩小网页：⌘ + -
		停止加载网页：Esc
		撰写包含网页链接的新电子邮件：⌘ + Shift + i
		打开 JavaScript 控制台：⌘ + Option + j
	鼠标快捷键
		打开链接：⌘ + 点击
		打开链接并跳转：⌘ + Shift + 点击
		在当前标签页中打开链接（拖动到标签页中）
		在新窗口中打开链接（按住 Shift 键点击）
