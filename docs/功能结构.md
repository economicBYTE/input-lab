## 功能模块说明

### 1. 内容中心

管理所有可练习的技术文档。

| 模块 | 功能点 | 优先级 | 说明 |
|------|--------|--------|------|
| 1.1 文档列表 | 列表展示 | P0 | 展示所有文档的标题和简介 |
| 1.1 文档列表 | 文档筛选 | P1 | 按分类/重点筛选文档 |
| 1.2 文档管理 | 新增文档 | P0 | 创建新的练习文档 |
| 1.2 文档管理 | 编辑文档 | P0 | 修改文档标题、内容等 |
| 1.2 文档管理 | 删除文档 | P0 | 删除不需要的文档 |
| 1.2 文档管理 | 导入文档 | P1 | 支持 JSON 格式导入 |
| 1.3 分类管理 | 分类列表 | P1 | 按技术栈分类（Git/SQL/JS等） |
| 1.3 分类管理 | 分类筛选 | P1 | 筛选指定分类的文档 |
| 1.4 重点标记 | 标记/取消标记 | P1 | 将文档标记为重点 |
| 1.4 重点标记 | 重点筛选 | P1 | 筛选重点文档 |

### 2. 打字练习

核心练习功能模块。

| 模块 | 功能点 | 优先级 | 说明 |
|------|--------|--------|------|
| 2.1 练习准备 | 选择文档 | P0 | 从列表选择要练习的文档 |
| 2.1 练习准备 | 智能推荐 | P1 | 根据错误率和重点推荐内容 |
| 2.2 练习过程 | 字符输入 | P0 | 逐字符对照输入，高亮当前字符 |
| 2.2 练习过程 | 错误处理 | P0 | 错误字符标红放大，强制重输 |
| 2.2 练习过程 | 实时统计 | P0 | 显示 KPM 和错误率 |
| 2.3 练习完成 | 完成统计 | P0 | 展示总时长、速度、错误率、错误字符 |

### 3. 数据统计

练习数据的记录和分析。

| 模块 | 功能点 | 优先级 | 说明 |
|------|--------|--------|------|
| 3.1 历史记录 | 记录列表 | P1 | 展示过往练习记录 |
| 3.1 历史记录 | 记录详情 | P1 | 查看单次练习详细数据 |
| 3.2 进度统计 | 练习进度 | P2 | 展示各分类完成度 |
| 3.2 进度统计 | 数据导出 | P2 | 导出练习数据为 JSON |

## 优先级分布

| 优先级 | 功能点数量 | 说明 |
|--------|------------|------|
| P0 | 8 | MVP 必须功能 |
| P1 | 10 | V1.0 版本功能 |
| P2 | 2 | 后续迭代功能 |
